**错误类型枚举**（不在枚举内则自行命名并写入备注，勿丢弃）：
`音高 / 时值 / 拍号 / 调号 / 谱号 / 反复记号 / 连音线 / 延音线 / 休止符 / 多声部归属 / 小节线缺失 / 乱码字符 / 歌词错位 / 页面顺序 / 缺失页`

- 高：影响音高或节拍正确性 → 必须修正后才能进 G2

- 低：排版/记号细节 → 可记录后批准
