# 质量门 G1 · 图像质量验收（OMR 输入前）

> 来源：#11 P0 定稿。
> 本文件是 G1 阈值的**唯一定义处**，各门 issue 只引用不重复定义。
> 通用约定：结论三态 `PASS` / `PASS_WITH_NOTES` / `FAIL`；每条检查项必须有**可复现命令或人工勾选记录**，禁止"看了觉得还行"；阈值快照落 `08_qc/gate_config.json`，逐项含 `value / adjustable / changed_by / changed_at / reason`。

## 位置与上下游

- 位置：管道 A 段末尾，进入 B（OMR）之前（对齐 #9）。
- 输入：`02_source/<song_id>/originals/` 原始图像（矢量 PDF / 扫描 PDF / 手机照片 / 手写 / 截图，分类见 #29）；预处理产物（见 #30）。
- 上游：#29 输入分类、#30 图像预处理；**门本体**：#31。

## 检查项

| # | 检查项（可测量） | 通过阈值（默认） | 可调 | 测量方式 |
|---|---|---|---|---|
| G1-1 | 有效分辨率（栅格化后按谱面区计算，非纸张整幅） | ≥ 300 dpi；单页短边 ≥ 2400 px；五线谱**线距 ≥ 8 px**（OMR 真正吃这个数） | 可调（≥200dpi 且线距≥6px 时可 PASS_WITH_NOTES，须记录） | `identify -format "%x %y %w %h"`；线距用直方图/傅里叶估计或人抽检 3 处 |
| G1-2 | 歪斜角（每页，预处理后） | 绝对值 **< 1°** | 可调（<2° 可 PASS_WITH_NOTES，须记录；≥2° 一律 FAIL） | deskew 算法输出角（#30），或人工以页边/谱线基准量角 |
| G1-3 | 裁切完整性 | 每页**系统起始小节**与**末小节**均未被切；无小节线/拍号被切半；页码与曲首标记（标题/速度/调号/拍号）完整 | 硬（不可放松） | 逐页勾选清单，逐条 `✓/✗` + 截图证据 |
| G1-4 | 页面顺序与缺页 | 与源文件页码顺序严格一致，**缺页数 = 0**，重复页 = 0 | 硬 | 页码序列比对 + 总页数核对 |
| G1-5 | 文字可辨性 | 歌词（韩/中/英）逐行可人工读出，**不可辨行数 = 0**；字高 ≥ 16 px | 可调（不可辨行数=0 为硬） | 逐页抽读，记录不可辨行号 |
| G1-6 | 音符符号可区分 | 在目标分辨率下**音符头 / 符尾数 / 附点 / 连音线 / 临时记号**可区分 | 硬 | 抽检 ≥5 处/页，出现任一不可区分即 FAIL |
| G1-7 | 单页信息密度 | 每页系统数 ≤ 6、小节数 ≤ 24（超出则拆页或重拍） | 可调 | 页级元素计数 |
| G1-8 | 分类与准入 | 手写 / 低质 / 畸变页**不得进入自动 OMR**；须转手动或分离试验（#29） | 硬 | 分类结果表逐页列出处置 |
| G1-9 | 原始文件只读 | `02_source/` 未被改动（mtime + 哈希校验） | 硬 | `sha256sum -c source_manifest.txt`（#13） |

## 失败处置

- 任一项 FAIL → **打回 A 段**：优先**重新获取/重拍/重新扫描**；不可复原时才允许 #30 允许范围内的预处理（拆页/deskew/旋转统一）。
- **禁止**以放大、二值化、锐化"美化"低质页来骗过门（#30 明确不过度加工）。
- 失败页在 `08_qc/gate_g1_report.md` 单独立行，标注「人难读 → 禁 OMR」。
- 打回 ≤2 轮仍 FAIL → 该页转人工录入路径，并在风险表（#14）登记。
