## 检查项

| # | 检查项（可测量） | 通过阈值（默认） | 可调 | 测量方式 |
|---|---|---|---|---|
| G4-1 | 响度（整体） | 流媒体目标 **−14 LUFS ± 1**（即 −15 ~ −13 LUFS，integrated） | 可调（CD 母带场景 −9~−12 LUFS，须显式改配置） | `ffmpeg -af loudnorm=print_format=json` 或 `loudgain` |
| G4-2 | 真峰上限 | **≤ −1 dBTP**（true peak，含 intersample） | 可调（≤−0.7 dBTP 为底线，不得 0 dBFS） | `ffmpeg loudnorm` true_peak 或 `ebur128` |
| G4-3 | 削波计数 | 达 **0 dBFS 采样数 = 0**（每轨与主总线均查） | 硬 | #60 脚本：削波样点统计 |
| G4-4 | 静音占比 | 有效乐段内异常静音 **= 0**；淡入淡出间隙静音须在白名单内 | 硬 | `08_qc/qc_file_check.py` 频谱 SILENCE 占比（#60） |
| G4-5 | 时长与预期一致 | master 时长 vs `小节 × 拍数 × BPM` 预期 **误差 ≤ ±1 秒** | 可调（±1s 为默认；纯现场/自由速度曲目另立记录） | `ffprobe -show_entries format=duration`（#60） |
| G4-6 | 结构可辨 | 主/副/桥**密度与动态差可辨**（段落标注见 #51）；段落对比听得出 | 硬 | 段落能量/EQ 对比表 + 人工勾选 |
| G4-7 | 声乐-伴奏关系 | 보컬 频谱在 **2~5 kHz 不被伴奏能量掩蔽**（#55）；速度/相位无抵消 | 硬 | #55 频谱比对 + 单声道合成确认无抵消消失（#58） |
| G4-8 | 单声道兼容 | 折叠单声道后无关键元素消失 / 无相互抵消 | 硬 | 单声道渲染 + A/B 试听勾选 |
| G4-9 | stem 完整性 | 鼓 / 贝斯 / 和声 / 보컬 stem 各自可重开、可同播、时长一致 | 硬 | `qc_file_check.py` 存在·大小·时长·频谱（#60） |
| G4-10 | 输出规格 | master 44.1k/24bit WAV + MP3 320 kbps；命名 `song_name_mix_v001.wav`（#13/#59） | 硬（规格）/ 可调（采样率按分发平台） | `ffprobe` 编码参数 |
| G4-11 | 全曲试听清单 | 逐段（Intro/Verse/Pre-chorus/Chorus/Bridge/Outro）**逐条勾选**，无未听项 | 硬 | 试听清单表格逐行 `✓` + 听者 + 时间 |
| G4-12 | 交付物齐全 | 原谱图 / 批准 MusicXML / 보컬 WAV / 编曲 MIDI / master WAV 均在分发文件夹；许可·版本·设置·批准日志齐全 | 硬 | 分发文件夹清单比对（#13 命名规则） |

## 失败处置

- 响度/真峰/削波 FAIL → **打回 F 段**（混音调整，优先改总线增益与限幅器设置），**不得以重采样或整轨降增益掩盖削波**。
- 静音/时长 FAIL → **打回 E 段**（编曲或渲染），核查 MIDI 长度与 BPM 设定。
- 声乐掩蔽/单声道抵消 FAIL → 打回 #58 混音检查项重做 EQ/相位。
- 试听未完成或有未勾选项 → **禁止判定 PASS**（对应 #14「仅轨道存在即批准」的阻断项）。
- 每次打回记录：`08_qc/qc_iterations.md`（轮次 / 原因 / 修改 / 重测结果）。
