# 质量门 G2 · 谱面审校门（MusicXML 冻结前）

> 来源：#11 P0 定稿。G2 阈值的**唯一定义处**。
> 通用约定同 gate_G1.md。

## 位置与上下游

- 位置：管道 C 段（MuseScore 全数审校，#35 的 8 步顺序）完成之后，进入 D 段之前。
- 输入：`03_omr/<song_id>/raw/` 各 OMR 候选导出 + `02_source/<song_id>/originals/` 原谱（**原谱为唯一裁判**）。
- 上游：#35 八步审校、#36 往返检查；**门本体**：#37。

## 检查项

| # | 检查项（可测量） | 通过阈值（默认） | 可调 | 测量方式 |
|---|---|---|---|---|
| G2-1 | 全局属性一致 | 标题 / 作曲 / **调号 / 拍号 / 速度 / 小节数 / 系统数** 与原谱逐项一致；不一致项 = 0 | 硬 | 逐项对照表（#35 步骤①） |
| G2-2 | 结构符号一致 | 反复 / 1·2 ending / DC·DS / 科达 全部一致 | 硬 | 结构对照表（#35 步骤②） |
| G2-3 | 节奏准确率 | 每小节**音长合计 = 拍号**，越界小节 = 0；附点 / 休止 / 三连音 / 跨小节连音逐处对照 | 音长合计硬；节奏准确率 ≥ **99.5%** 可调 | 小节级比对脚本 + 人工听回放（#35 步骤④） |
| G2-4 | 音高准确率 | 逐小节（含临时记号 ♯♭♮）对照：音高错误数 = 0 | 硬 | 音符级 diff：候选 MIDI 对齐原谱 |
| G2-5 | 歌词音节-音符对应 | **音节-音符映射正确率 = 100%**；韩文无乱码；连字符（-）与延长（—）区分正确 | 硬 | 音节级逐项核对（#35 步骤⑦） |
| G2-6 | 导出-再导入往返一致 | MusicXML 导出→重新导入，**歌词丢失数 = 0**、音符数 / 小节数 / 调号 / 拍号不变（#36） | 硬 | 两次解析的规范化 JSON diff |
| G2-7 | 基准文件无解析错误 | `ground_truth.musicxml` 用目标工具（MuseScore / ACE #38）打开**未解错误 = 0** | 硬 | 工具打开日志 |
| G2-8 | 人工修正耗时 | 记录 `human_correction_time`（分钟/页），作为工具选型轴（#10） | 仅记录，不设阈值；**不设上限**避免为省时间放水 | 审校者计时 |
| G2-9 | 冻结完整性 | 生成 `04_approved/ground_truth.musicxml` + `ground_truth_hash.txt`（SHA-256 + 批准时间 + 批准人） | 硬 | `sha256sum ground_truth.musicxml` 比对 |

## 冻结定义（对齐 #13）

G2 PASS 时把 `04_approved/<song_id>/ground_truth.musicxml` 置为**只读不可变**；此后任何修改生成 `v002`，**不得原地覆盖**；下游（D/E 段）一律以哈希校验读取。

```text
04_approved/<song_id>/ground_truth.musicxml
04_approved/<song_id>/ground_truth.musicxml.sha256   # <sha256>  <file>  <utc_time>  <approver>
```

## 失败处置

- 音高/时值/歌词类 FAIL → **打回 C 段** 逐项修正后重跑 G2（禁止"改基准音符去迁就 AI 输出"，见 #43）。
- 往返一致 FAIL 且歌词无法保留 → 转 **ACE 手动歌词路径**（#36）：MusicXML 仅作旋律/节奏基准，歌词以 `08_qc/lyric_mapping.csv` 人工表为准。
- 修正过程与页级错误记 `08_qc/score_qc_report.md`（#47）；重复性风险登记至 #14。
