# 质量门 G3 · 声乐批准门（vocal WAV 冻结前）

> 来源：#11 P0 定稿。G3 阈值的**唯一定义处**。
> 通用约定同 gate_G1.md。

## 位置与上下游

- 位置：管道 D 段末尾，进入 E（编曲）之前。
- 输入：`04_approved/<song_id>/ground_truth.musicxml`（只读）+ `05_vocals/<song_id>/projects/` 与（条件触发时）SV2 的 8 小节同基准渲染 WAV（#43/#44）+ 声库与参数记录（#46）。
- 上游：#40 音节-音符全数核对、#42 音高校验、#45 A/B 评测与引擎选定；**门本体**：#46。

## 检查项

| # | 检查项（可测量） | 通过阈值（默认） | 可调 | 测量方式 |
|---|---|---|---|---|
| G3-1 | 可用渲染产物 | 基准 8 小节在 ACE **及**（触发条件成立时的）SV2 均产出 WAV；文件存在、可解码、非静音 | 硬 | `ffprobe` + 静音检测（#60 同款脚本） |
| G3-2 | 音高偏差 | 与基准 MIDI 叠加比：**逐音符偏差绝对值 ≤ 30 音分**；**中位偏差 ≤ 15 音分**；超阈音符数 = 0 | 可调（≤50/≤25 音分可 PASS_WITH_NOTES 并记录；>50 音分必 FAIL） | 逐音符 F0 提取（librosa/pyin 或工具自带 pitch 曲线）+ 基准对齐；#42 钢琴卷帘叠加人核 |
| G3-3 | 音节-音符对应 | **映射错误数 = 0**（含长延长、1 音节-多音符处，须逐处核对，见 #40） | 硬 | `08_qc/vocal_lyric_mapping.csv` 逐音节核对表；不符即还原原音符或明确记录 |
| G3-4 | 节拍位置精度 | 音节起始拍位与基准偏差 ≤ **±30 ms**（8 小节内 100% 命中） | 可调（±50 ms + 记录） | onset 检测对齐基准网格 |
| G3-5 | 发音可懂度 | #45 评测表中 **「韩语发音明度」≤ 3 的引擎不得采用** | 硬（沿用 #45 门槛） | A/B 评测表打分（1-5） |
| G3-6 | A/B 结论成立 | 评测 7 项全部打分完成，**不唯总分**；选定引擎 + 理由写入报告 | 硬 | `08_qc/vocal_ab_report.md`（#45） |
| G3-7 | 速度/调性一致 | 보컬 clip 速度与基准 MIDI 长度合计（小节×拍数×BPM）一致；调性/拍号无二次转写 | 硬 | 长度合计比对（#38 只读验证） |
| G3-8 | 参数可复现 | `vocal_settings.json` 记录：引擎+版本 / 声库+版本 / 语言 / 主要参数（气声、音素、力度等）/ 渲染模式（云 or 高性能） | 硬 | 字段齐全性校验（#46） |
| G3-9 | 人工修正耗时 | 记录 `human_correction_time`（分钟/8 小节），仅作选型参考 | 仅记录 | 审校者计时 |
| G3-10 | 冻结完整性 | `05_vocals/<song_id>/vocal_wav/approved_vocal_pilot.wav` 固定 + SHA-256 记录 | 硬 | 哈希记录文件 |

## 失败处置

- 音高/音节类 FAIL → **打回 D 段**，按 **音符 → 歌词 → 参数**顺序修后重渲（#43）；**不得靠改基准音符解决**。
- 引擎整体不达标（如 G3-5 触发）→ 依 #45/#44 换引擎或触发 SV2 对比路径，重跑 G3。
- 未通过即渲染为"完成品"→ 视为风险 #14「只建伴奏无声/重复单调」同类，登记并回退。
