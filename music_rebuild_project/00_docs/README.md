# 00_docs · 规划 / 门标准 / 交付物清单

## 放什么

- `plan/`：01~05 规划书索引
- `gates/`：G1~G4 判定标准（`gate_G1.md` ~ `gate_G4.md`）
- `deliverables.md`：交付物 → 目录落位映射
- `glossary.md`：术语表（song_id / gate / approved / retest）
- `failure_recovery.md`：常见失败恢复文档（#62）

- 实际媒体文件（音频/乐谱）——落在 `02_source/` 起的各数据目录
- 门下发的判定**记录** → `08_qc/`
