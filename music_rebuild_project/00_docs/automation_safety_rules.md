# Agent 自动化安全红线（CodeBuddy / Agent 必读）

> 来源：#57（[阶段4] CodeBuddy 自动化—编曲提示词与安全规则）。
> 定位：本文是**自动化 Agent 的行为红线**，用于防止越权写数据目录、破坏冻结件、用美化手段骗过质量门。
> 规则**全部继承既有约定**（gate_G1/G2/G3/G4、#13、#27、#43、`00_docs/README.md`），**不另造阈值**。
> 与门标准冲突时**以门标准为准**，本文只做「动作级」落地。
> 配套提示词模板：`00_docs/arrangement_prompts.md`。

## 0. 一句话原则

**冻结件只读、基准是唯一裁判、越权即停。**
Agent 可以读一切、可以在工作区造新东西；**不可以**改历史、不可以改基准去迁就 AI、不可以用手段骗门。

## 4. 幂等与可回滚

每次自动化动作必须满足「**可重跑、可审计、可回滚**」：

| 要求 | 落地方式 |
|---|---|
| 可重跑（幂等） | 同一命令重复执行结果一致；产物按 `vNNN` 递增，**不覆盖**已有文件；不用「原地追加」式修改 |
| 可审计 | 记录：动作 / 命令 / 时间(UTC) / 依据的基准哈希 / 产出路径 + 音符数 + 小节数 |
| 可回滚 | 旧版本文件永久保留（#13）；回滚 = 重新指向旧版本，而非删文件 |
| 可校验 | 冻结件用 `tools/checks/verify_hashes.sh` 按 `*.sha256` 校验；只读位用 `tools/checks/check_ro.sh` |
| 留痕位置 | 编曲动作记录落 `06_arrangement/<song_id>/`；门判定追加 `08_qc/<song_id>/gate_log.md`（不改历史行） |

> 幂等不等于「可以随便重跑破坏冻结件」：重跑只允许产出**新版本**，永不原地改写已存在文件。

## 5. 越权时的正确行为：停下并报告

发现下列任一情况，Agent **必须立即停止当前动作**，输出报告，**不得自行降级继续**：

1. 输入契约缺失（基准谱不存在 / 哈希校验不通过 / 段落标注或批准后的 `chords.txt` 缺失）；
2. 目标路径落在冻结区（`02_source/`、`04_approved/`、`05_vocals` 批准件、`07_mix/masters|dist`、`09_archive/`）；
3. 完成任务需要修改基准音符/歌词，或需要原地覆盖冻结件；
4. 需要绕过权限控制（如添加 skip-permissions、放开 MCP 全域）才能继续；
5. 需要「删文件 / 覆盖文件」才能继续；
6. 门判定 FAIL，且正确处置需要回到上游阶段（A/C/D/E/F 段）——此时**升级给人**，不自行掩盖。

**报告格式（最小集）**

```text
[STOP] 停止原因：<契约缺失 / 命中冻结区 / 需改基准 / 需提权 / 门 FAIL ...>
证据：<路径 + 哈希值 / 命令输出 / 命中规则编号 F-x>
已执行动作：<命令 + 产物路径 + 是否产生残留>
建议：<应回到哪一段 / 需要人工批准什么>
```

> 原则：**停 = 正确行为**。以「先凑一个出来」为由的降级继续（改基准、覆盖冻结件、美化骗门）一律视为违规。
