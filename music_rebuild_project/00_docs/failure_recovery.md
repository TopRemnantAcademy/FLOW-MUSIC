# 常见失败与恢复流程（failure_recovery）

> 来源：#62（Wave 3）。本文件只回答一个问题：**门 FAIL 之后怎么办。**
> **阈值不在本文件定义**——G1~G4 的阈值、可调性、测量方式一律以 `00_docs/gates/gate_G1.md` ~ `gate_G4.md` 为准（那里是唯一定义处，见 `00_docs/gates/README.md` 幂等约定）。
> 本文件只做三件事：把各门「失败处置」段落落成**可执行路径**、给出**打回记录要求**、划出**禁止手段红线**。
> 推不出来的处置一律标「**待定**」，不臆造。

## 通用流程（四门共用）

```
FAIL
 └─ 1. 定位：哪一项检查项 FAIL，证据（命令输出 / 勾选记录 / 截图）落在该门的报告文件
 └─ 2. 归因：属"输入/素材问题"还是"处理参数问题"（决定回退到哪一段，见下表）
 └─ 3. 恢复：按该门"失败处置"列出的动作执行（不得跳步、不得换用禁止手段）
 └─ 4. 回退：退回到指定段（A/C/D/E/F）修复，**从该段之后按顺序重跑**，不跳门
 └─ 5. 登记：写 `08_qc/qc_iterations.md`（轮次/原因/修改/重测结果）；
          可复用风险写 `01_preflight/risk_register.md`（#14）；环境类写 `01_preflight/issue_log/`（#28）
 └─ 6. 重测：重跑该门，产出新的报告行；**历史结论不追溯改写**（L2 只追加）
```

回退去向总表（与各门「失败处置」一致）：

| 门 | 失败类别 | 回退到 | 出处 |
|---|---|---|---|
| G1 | 任一项 FAIL | A 段（重新获取/重拍/重新扫描） | gate_G1 失败处置 |
| G2 | 音高 / 时值 / 歌词类 FAIL | C 段（逐项修正后重跑 G2） | gate_G2 失败处置 |
| G2 | 导出-再导入往返一致 FAIL 且歌词无法保留 | 转 ACE 手动歌词路径（MusicXML 仅作旋律/节奏基准） | gate_G2 / #36 |
| G3 | 音高 / 音节类 FAIL | D 段，按 音符 → 歌词 → 参数 顺序修后重渲 | gate_G3 失败处置 |
| G3 | 引擎整体不达标 | 换引擎或触发 SV2 对比路径后重跑 G3 | gate_G3 / #44 #45 |
| G4 | 响度 / 真峰 / 削波 FAIL | F 段（优先改总线增益与限幅器设置） | gate_G4 失败处置 |
| G4 | 静音 / 时长 FAIL | E 段（核查 MIDI 长度与 BPM 设定） | gate_G4 失败处置 |
| G4 | 声乐掩蔽 / 单声道抵消 FAIL | #58 混音检查项，重做 EQ / 相位 | gate_G4 失败处置 |
| G4 | 试听未完成 / 有未勾选项 | 不许判 PASS；补齐试听清单后重跑 | gate_G4 失败处置 |

闭环判定：**PASS_WITH_NOTES** 不算失败，但须按 `glossary.md` 记录已知偏差并追认；`FAIL` 才走本文件流程。

## G1 · 图像质量验收（打回 A 段）

| 症状 | 归因（排查方向） | 恢复动作 | 回退到 | 登记到 |
|---|---|---|---|---|
| 分辨率/线距不足（G1-1） | 采集设备、扫描设置、原稿尺寸 | 重新获取 / 重拍 / 重新扫描（提高 dpi、缩短距离、换设备） | A 段 | `08_qc/gate_g1_report.md` 单行 + `08_qc/qc_iterations.md` |
| 歪斜超限（G1-2） | 拍摄角度、扫描走纸 | 重拍重扫为首选；不可复原时仅在 #30 允许范围内预处理（去斜） | A 段 | 同上 |
| 裁切不完整（G1-3）、缺页/重页（G1-4） | 拍摄取景、扫描区间 | 重新获取缺失/受损页，保持页码顺序与原文件一致 | A 段 | 同上 |
| 文字不可辨（G1-5）、符号不可区分（G1-6） | 原稿清晰度、成像质量 | 重新获取；不可复原 → 该页标注「人难读 → 禁 OMR」 | A 段 | `gate_g1_report.md` 单行（标注禁 OMR） |
| 单页密度超限（G1-7） | 版式本身密集 | 拆页或重拍（#30 允许范围内） | A 段 | `gate_g1_report.md` |
| 手写/低质/畸变页（G1-8） | 输入分类命中禁 OMR 类 | **不得进入自动 OMR**，转手动录入或分离试验（#29） | A 段 / 人工路径 | `01_preflight/manifest.csv` 处置列 |
| 原始文件被改动（G1-9） | 预处理误写回 `02_source/` | 用哈希清单定位被改文件，按 v002/重新入库恢复，禁止原地"修回" | A 段 | `issue_log/env_*.md` + `risk_register.md` |

**失败升级**：打回 **≤2 轮仍 FAIL** → 该页转**人工录入路径**，并在 `01_preflight/risk_register.md`（#14，当前对应 R-01 输入质量 / 工具能力）登记。

禁止手法见下方「禁止的掩盖手段」第 1 条。

## G2 · 谱面审校门（打回 C 段）

| 症状 | 归因 | 恢复动作 | 回退到 | 登记到 |
|---|---|---|---|---|
| 全局属性/结构符号不一致（G2-1/G2-2） | 审校漏改、原谱读错 | 对照原谱逐项修正后再跑 G2（原谱为唯一裁判） | C 段 | `08_qc/score_qc_report.md`（#47）+ `qc_iterations.md` |
| 节奏/音高类 FAIL（G2-3/G2-4） | OMR 识别错、审校漏 | 逐小节/逐音符修正候选稿；对照对象是**原谱**，不是 AI 输出 | C 段 | 同上 |
| 歌词音节-音符对应错（G2-5） | 分音节/连字符处理错 | 逐音节核对修正后重跑 G2 | C 段 | 同上 |
| 往返一致 FAIL（G2-6、歌词丢失） | 导出/再导入丢歌词 | 歌词无法保留 → 转 **ACE 手动歌词路径**（#36）：MusicXML 仅作旋律/节奏基准，歌词以 `08_qc/lyric_mapping.csv` 人工表为准 | C 段 → ACE 路径 | `score_qc_report.md` + `xml_roundtrip_check.md` |
| 基准文件解析报错（G2-7） | 文件本身非法 | 修至目标工具打开无解错误后再走冻结 | C 段 | `score_qc_report.md` |
| 冻结完整性缺失（G2-9） | 哈希/批准信息未落 | 补 `ground_truth_hash.txt`（SHA-256 + 批准时间 + 批准人）；**已冻结文件改动须生 v002，不得原地覆盖** | C 段 | `04_approved/<song_id>/` + `risk_register.md`（R-03 数据漂移） |

重复出现的同类错误 → 登记 #14（当前对应 R-02 工具能力；若是被下游就地改动则对应 R-03）。

禁止手法见「禁止的掩盖手段」第 2 条。

## G3 · 声乐批准门（打回 D 段）

| 症状 | 归因 | 恢复动作 | 回退到 | 登记到 |
|---|---|---|---|---|
| 音高偏差超限（G3-2） | 引擎/声库/参数、基准音符与歌词输入 | 按 **音符 → 歌词 → 参数** 顺序修后重渲，再跑 G3 | D 段 | `08_qc/gate_g3_report.md` + `qc_iterations.md` |
| 音节-音符映射错误（G3-3） | 分音节、长延长、1 音节-多音符处理 | 逐处核对修正后重渲（#40） | D 段 | `08_qc/vocal_lyric_mapping.csv` + 同上 |
| 节拍位置偏差（G3-4） | 时序/曲速设置 | 修时序后重渲 | D 段 | `gate_g3_report.md` |
| 可用渲染产物缺失/静音（G3-1） | 引擎未产出、导出失败 | 排查导出与解码（#60 同款脚本），修复后重渲 | D 段 | `issue_log/` + `gate_g3_report.md` |
| 发音可懂度不达标（G3-5，明度 ≤3） | 引擎/声库本身能力 | **该引擎不得采用** → 依 #45/#44 换引擎或触发 SV2 对比路径，重跑 G3 | D 段（换路径） | `vocal_ab_report.md` + `risk_register.md`（R-04 보컬质量） |
| A/B 结论不成立（G3-6，7 项未打全） | 评测未做完 | 补全 7 项打分（**不唯总分**）后重出结论 | D 段 | `vocal_ab_report.md` |
| 速度/调性不一致（G3-7） | 二次转写、clip 长度错 | 按基准 MIDI 长度合计校正后重渲 | D 段 | `gate_g3_report.md` |
| 参数不可复现（G3-8） | `vocal_settings.json` 字段缺 | 补齐引擎+版本/声库+版本/语言/主要参数/渲染模式 | D 段 | `05_vocals/<song_id>/vocal_settings.json` |
| 未过门即渲染成"完成品" | 跳过门直接产出 | 回退，按 #14 同类风险登记（对齐「只建伴奏无声/重复单调」类） | D 段 | `risk_register.md` |
| 冻结完整性缺失（G3-10） | 哈希未记 | 补 `approved_vocal_pilot.sha256`（配套 `vocal_settings.json`） | D 段 | `05_vocals/<song_id>/vocal_wav/` |

## G4 · 最终 QC 门（打回 F 段 / E 段）

| 症状 | 归因 | 恢复动作 | 回退到 | 登记到 |
|---|---|---|---|---|
| 响度超限（G4-1） | 总线增益、限幅器 | 调总线增益与限幅器设置后重渲 | F 段 | `08_qc/qc_report.md` + `qc_iterations.md` |

| 削波计数非 0（G4-3） | 增益结构错 | **优先改总线增益与限幅器设置**；重渲后重跑 #60 脚本 | F 段 | 同上 |
| 异常静音（G4-4） | 编曲空段、渲染漏段、淡入淡出白名单未备案 | 核查编曲/渲染，白名单外的静音须消除 | E 段 | `qc_report.md` + `mix_checklist.md` |
| 时长不一致（G4-5） | MIDI 长度、BPM 设定 | 核查 MIDI 长度与 BPM 设定后重渲 | E 段 | 同上 |
| 声乐被掩蔽（G4-7，2~5 kHz） | 伴奏 EQ 占用、编曲密度 | 打回 #58 混音检查项，重做 EQ / 相位 | #58 检查项 | `mix_checklist.md` + `risk_register.md`（R-05 编曲干扰） |
| 单声道抵消（G4-8） | 相位问题 | 同上，重做相位并单声道复听确认 | #58 检查项 | 同上 |
| 结构不可辨（G4-6） | 编曲/混音动态 | 参照段落标注（#51）调整密度与动态差，重渲复查 | E/F 段（按归因） | `qc_report.md` |
| stem 不完整（G4-9） | 导出漏项 | 重新导出并跑 `qc_file_check.py`（存在/大小/时长/频谱） | F 段 | `verify_report.md` |
| 输出规格/命名不符（G4-10） | 导出设置、命名规则 | 按规格重导，命名对齐 #13/#59 | F 段 | `verify_report.md` |
| 试听未完成（G4-11） | 清单有未勾选项 | **禁止判 PASS**；逐段（Intro/Verse/Pre-chorus/Chorus/Bridge/Outro）补勾并署名+时间 | F 段 | `08_qc/qc_trial_list.md` |
| 交付物不全（G4-12） | 分发清单漏项 | 按清单补齐（原谱图/批准 MusicXML/보컬 WAV/编曲 MIDI/master WAV + 许可·版本·设置·批准日志） | F 段 | `approval_log.md` + `risk_register.md`（R-06 交付残缺） |

> 试听未完成 / 有未勾选项属 #14「仅轨道存在即批准」的**阻断项**：不是"下次补"，是**当轮不得 PASS**。

禁止手法见「禁止的掩盖手段」第 4 条。

## 每次打回的记录要求

统一落在 `08_qc/qc_iterations.md`（出处：gate_G4 失败处置），**每轮一行/一段，只追加不改写**（`08_qc/README.md`：L2 只读/只追加）：

| 字段 | 填写要求 |
|---|---|
| 轮次 | 递增序号（round 1, 2, 3…），与门的重跑次数对应 |
| 原因 | 哪个门、哪个检查项 FAIL + 实测值（**写实测值，不写"效果不好"**） |
| 修改 | 具体改了什么（参数/素材/工程文件版本号），不含糊 |
| 重测结果 | 重跑后的结论（PASS / PASS_WITH_NOTES / FAIL）与证据文件 |

其余登记分流：

- 可复用/复发风险 → `01_preflight/risk_register.md`（#14），对齐现有 R-01~R-06
- 环境/工具故障 → `01_preflight/issue_log/env_YYYY-MM-DD_<slug>.md`（#28，只追加）
- 未过门或被取代的版本 → `09_archive/YYYY-MM/` + `ARCHIVE_NOTE.md`，不原地删

## 禁止的掩盖手段（红线）

以下手段**即使能让门"看起来 PASS"也一律禁止**；用了 = 判定无效，须回退重做：

1. **美化低质图骗过 G1**：放大、二值化、锐化等"美化"低质页以凑够分辨率/线距（gate_G1 失败处置；#30 明确不过度加工）。正确路径：重新获取/重拍/重扫。
2. **改基准音符去迁就 AI 输出**：以引擎/OMR 输出反推修改 `ground_truth.musicxml` 或候选谱（gate_G2 失败处置，见 #43）。**原谱是唯一裁判**；基准已冻结则只能生 v002 并留理由。
3. **靠改基准音符解决声乐问题**：G3 音高/音节 FAIL 时改基准而非按 音符 → 歌词 → 参数 修（gate_G3 失败处置）。编曲阶段声乐轨音符/歌词只读（`deliverables.md` 冻结规则）。
4. **以重采样或整轨降增益掩盖削波**：G4 削波 FAIL 时用重采样/整体压增益制造"无削波假象"（gate_G4 失败处置）。正确路径：回 F 段改总线增益与限幅器设置。
5. **未完成检查即判 PASS**：试听清单有未勾选项、A/B 7 项未打完就打结论（gate_G2/G3/G4；#14 阻断项）。
6. **无证据判定**：只凭"看了觉得还行"给结论（gate_G1 通用约定：每条检查项必须有可复现命令或人工勾选记录）。
7. **就地改写冻结件**：`04_approved/**`、`08_qc/gate_log.md` 历史行、`09_archive/**`（L2 只读/只追加；#13/#27）。要改就生新版本。
