# 02_source · 原始乐谱 · 只进不改

## 放什么

- `<song_id>/originals/`：扫描件 / 照片 / PDF **原样保留**
- `<song_id>/preprocessed/`：去斜 / 分页 / 旋转统一后的图像（#30）
- `<song_id>/manifest.md`：来源 / 页数 / DPI / 时间 / sha256 / 采集人

## 不放什么

- OMR 产物 → `03_omr/`
- 任何"美化"过的图（放大/二值化/锐化骗门，禁止，#30）

## 只读规则

**强只读（L0，append-only）**。文件系统级只读加固（#27），mtime + 哈希校验（G1-9）。改进只能新增文件，不改旧文件。
