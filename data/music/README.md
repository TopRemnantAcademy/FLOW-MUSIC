# 묵상 음원 폴더

이 폴더에 오디오 파일(mp3/ogg/m4a/wav)을 넣으면 자동으로 찬양 카탈로그에 추가됩니다.

## 파일명 규칙

```
{번호}-{제목}.mp3
```

예:
- `01-새힘.mp3`
- `02-은혜의아침.mp3`

또는 단순히 제목만:
- `새힘.mp3`

## 동작 방식

1. 이 폴더에 파일이 있으면 → `type: "file"` 로 카탈로그에 추가, `/mobile/music/{id}/stream` 으로 스트리밍 재생
2. 파일이 없는 기본 트랙은 → `type: "generated"` 로 Web Audio 합성 폴백

## 라이선스 안내
